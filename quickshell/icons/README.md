# Lucide icons

SVG geometry from [Lucide 0.577.0](https://github.com/lucide-icons/lucide/tree/0.577.0/icons).
Strokes are black (`#000000`) for contrast on the light sidebar; geometry is unchanged.
These small, vendored SVGs avoid font dependencies and runtime downloads.
